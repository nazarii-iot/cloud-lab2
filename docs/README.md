Документація лабораторної роботи 2

Цей каталог містить опис реалізації, результати вимірювань і графічні докази роботи REST-сервісу в AWS.

RESULTS_SUMMARY.md — загальний підсумок реалізації, перевірок і вимірювань.

AUTOSCALING.md — конфігурація ECS Service Auto Scaling, обґрунтування цільового значення, cooldown та фактична часова шкала масштабування.

LOADTEST.md — параметри хмарного навантажувального тесту, агреговані показники, аналіз затримок і розташування сирого результату.

CACHE.md — конфігурація Redis, cache-aside, TTL, інвалідація та порівняння сценаріїв кешування.

ALERTS.md — конфігурація CloudWatch alarms, SNS та фактичні часові позначки повідомлень ALARM і OK.

SCREENSHOTS.md — графічні докази CloudWatch Dashboard і доставки SNS-повідомлень.

Каталог screenshots містить зображення панелі моніторингу та електронних повідомлень SNS, на які посилаються відповідні розділи звіту.
