Навантажувальне тестування

Для тестування створено скрипт loadtest/load_test.py.

Кожен користувач створює один запис, після чого виконує 8–10 запитів на читання.

Команда запуску:

python .\loadtest\load_test.py --url $baseUrl --users 30 --ramp-up 180 --steady 300 --ramp-down 120

Користувачі: 30.
Ramp-up: 180 секунд.
Steady: 300 секунд.
Ramp-down: 120 секунд.

Результати:

Кількість запитів: 3311.
Частка помилок: 0,0302%.
p50: 148,97 мс.
p95: 20085,35 мс.
p99: 20180,32 мс.

Одна помилка виникла через тайм-аут запиту до /author. Високі значення p95 та p99 пов'язані з тайм-аутом клієнта.

Під час тесту AWS автоматично збільшив кількість завдань до 4, а після зменшення навантаження — до 3.
